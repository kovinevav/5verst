# 5verst

Раннер про забеги 5 км по городам. Главная героиня — Марина, бежит вправо, собирает пятюни, прыгает через лужи. Надо уложиться в лимит времени (на первом уровне 30 минут, дальше меньше). Каждая пятюня добавляет скорости, лужа наоборот замедляет скорость. Сделано на LibGDX, под Android и desktop.
Дизайн под 1280×720, landscape.

## Запуск

**С компьютера (без эмулятора):**
```bash
./gradlew :desktop:run
```

**APK:**
```bash
./gradlew :android:assembleDebug
```
apk лежит в `android/build/outputs/apk/debug/`

На десктопе тапы работают мышкой.

## Модули

- `core` — вся логика и экраны
- `android` — сборка под телефон
- `desktop` — под десктоп


Ассеты в папке `assets/` (фоны, marina_run, пятюни, звук и т.д.)

## Основные классы

### Точка входа

**MyGdxGame** — наследник `Game`. Тут batch, камера, ExtendViewport, SaveService, AudioService. Переключение экранов: `showMenu()`, `showGame()` и остальное.

### Экраны (`screens/`)

| Класс | Что делает |
|-------|------------|
| MenuScreen | меню, выбор города, фишки |
| GameScreen | сам забег, коллизии, HUD, пауза |
| StatsScreen | статистика последнего забега |
| LevelCompleteScreen | победа, танец Марины, кнопка следующего города |
| AchievementsScreen | достижения |
| SettingsScreen | звук, сброс прогресса (там двойное подтверждение) |

### Игра (`game/`)

**RunRules** — константы: 5 км, лимиты времени по городам, форматирование времени/темпа/км.

**PaceTracker** — «секундомер» забега и темп. Пятюни ускоряют, лужи тормозят. Базовый темп 6:10, на экране может падать до 4:00 если много бонусов.

**GameState** — enum: PLAYING, PAUSED, GAME_OVER, VICTORY.

**MovingBackground** — прокрутка фона, ближе к финишу подменяется finish-картинка.

**StatsPanel** — рисование карточек, кнопок, строк статистики (без Scene2D, всё через batch и белый пиксель).

**CitySplashBackground** — заставка города на экране статистики (`cities/N.png`).

**CityFishkiDisplay** — фишки городов в меню / на победе.

**FontAssets** — шрифт Liberation Sans + кириллица.

### Города (`game/cities/`)

**City** — данные одного уровня: имя, пути к фонам, лимит времени, целевой темп.

**CityRegistry** — все 10 городов в одном массиве. `get()`, `getNext()`, `getSplashPath()`, `clampIndex()` и т.п.

### Сущности (`game/entities/`)

**AbstractRuner** — база для бегунов (координаты, кадры, draw).

**PlayRuner** — Марина. Прыжок, гравитация, `preciseY` для плавности, анимация бега.

**PassingRunner** — вторая девочка на фоне (girlRun), чисто декор.

**Pyatyunya** — коллекционка на дороге, общий PyatyunyaAnimator.

**Puddle** — лужа, надо перепрыгнуть.

### Компоненты (`game/components/`)

**PyatyunyaAnimator** — 4 кадра пятюни, цикл по времени.

**MarinaDanceAnimator** — танец на экране победы.

**Button** — кнопка в меню/настройках.

### Сервисы (`game/services/`)

**SaveService** — Preferences `"5verst"`: прогресс, города, рекорд, последний забег, достижения, настройки звука.

**AudioService** — музыка (game, win, theEnd) и звуки (прыжок, сбор, game over, пауза).

## Геймплей вкратце

10 городов, от Новосибирска до Питера. Каждый — те же 5 км, но на минуту меньше лимит чем на предыдущем. Пятюни почти обязательны на поздних уровнях. Прошёл — открывается следующий город и ачивка.
